   `#` comment as well as `!`, as MadGraph's `banner.py` does (check

   start versus mid-line, and whether a value can itself contain `#`).

     `<v> = <name>`, for at least one Float, one Bool and one consumed field.

     own default `run_card.dat` template(s) used by the repo's tests and
     fixtures still parse with no new refusal, and list in the report every
     fixture whose reading changed.

     same line of code and the fix is forced; if so, say so.
2. **Systematics warning.** A card with `use_syst = True` and

   other warnings are emitted and follow that path; a test captures the
