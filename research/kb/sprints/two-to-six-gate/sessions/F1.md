## Scope

1. **Environment parameters**, defaults unchanged so today's invocation is the
   same:
   - `VG_2TO6_ROWS` (default both rows);
   - `VG_2TO6_SAMPLERS` (`flat`, `multi`, default both);
   - `VG_2TO6_RUNGS` (comma list of neval, per sampler, default today's);
   - `VG_2TO6_SEEDS` (either a count `N`, meaning `SEED` plus the next N − 1
     from a documented scheme, or an explicit comma list; default today's
     five);
   - `VG_2TO6_NITER` (default 8);
   - `VG_2TO6_OUT` (a TSV path: row, sampler, neval, niter, seed, σ, error,
     wall seconds).
   Write one line per seed as it finishes and flush it, so a killed run keeps
   what it measured.
2. **The reference.** Print and record the pull against the row's refdata-10
   seed record, read the way the gate reads it, beside the old
   `sigma_reference.json` value. Today the probe reads only the latter.
3. **A summary line per rung**: unweighted mean, max(quoted, spread/√n),
   χ²/dof, pull. For each adjacent pair of rungs, also the D1
   fourth-amendment reading (Δmean against σ = √(s₁²/n₁ + s₂²/n₂) from the
   measured spreads) as information.
4. **The command** for the user, in the probe's doc comment: the 600k and 1.2M
   multichannel rungs, 20 seeds, both rows, release-debug, extended-validation,
   detached; expected output files; a rough time per seed scaled from P1's
   measurements.
5. **Prove it on this host at a toy budget.** One row, `multi`, one rung at the
   channel floor, two seeds, `VG_2TO6_NITER=2`. Show the TSV and the summary.
   Stop it if it runs past ~20 min.
