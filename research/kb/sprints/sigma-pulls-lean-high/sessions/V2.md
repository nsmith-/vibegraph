## Scope

1. **The estimator.** A fixed-density importance sampler for `uux_to_epemg`,
   with `ddx_to_epemg` as control. Its density is chosen once, analytically or
   from a frozen grid that is never refined during the measurement. No
   iteration weighting and no adaptation enter the estimate, so its error is
   the plain sample error. The integrand is this crate's own |M|² and cuts, so
   the estimate checks the references, not this side's matrix element (that is
   gated elsewhere). Commit it as an `#[ignore]`d probe beside #22's.
2. **Precision.** Enough points that its error is well below the gap it must
   decide. MadEvent's reported 0.555054 ± 0.000448 pb, EW 0.556177 and this
   side 0.556723 sit about 0.2 % apart, so aim for ≤ 0.05 %. Show it is
   honest: over ≥5 independent seeds, χ²/dof of the seed values about their
   mean.
3. **Verdict per row:** the estimate's pull against the record's reported
   mean, its equal-weight mean and this side's five-seed mean (from F1's
   recorded run). D1's condition is met when it lands on EW (|pull| < 2) and
   not on the reported value.
4. **If it lands on EW**, set `validated_ew` on `uux_to_epemg`, `ddx_to_epemg`
   and `ee_to_mumu_tata_qcd0` the way the reader takes it. If the flag lives
   only in the banked records (`seed_record.json`), do **not** edit banked
   data: write the exact banking or record-patch request for the user, and
   propose a committed override only if the reader already has one. Report
   which applies. If it does not land on EW, nothing is set; record why.
