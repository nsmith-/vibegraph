## Scope

1. **Ladder verdict.** For a record carrying ≥20 seeds at 1× and ≥20 at 4×,
   `seed-record` (and `--rescreen`) prints the D1 fourth-amendment verdict:
   σ = √(s₁ₓ²/n₁ₓ + s₄ₓ²/n₄ₓ) from the sample standard deviations of the
   reported values (quoted errors do not enter); "re-bank at 4×" if
   |mean₄ₓ − mean₁ₓ| > 2σ, else "stays at 1×". Below 20 + 20 it says the
   ladder is not run. The `SCREEN` line is unchanged. Pin it with a test that
   reproduces `ll_to_qqx_toy_dipole`'s hand-read −0.87σ if its 20 + 20 ladder
   is in the bundle (look under `validation/madgraph/output/seeded_sigma/`);
   otherwise a synthetic record on both sides of 2σ.
2. **20-seed recipe.** `bank_seeded_sigma.sh` documents (and, if cheap, offers
   through an env var) how a SCATTER-flagged row is confirmed on 20 seeds:
   which variables (`SEEDS`, a separate `SEEDED_OUT`), which record is then
   banked, and how `seed-record` reads it. It must be something the user can
   run on the M3 from the doc alone.
3. **Tie-break.** SCATTER's worst channel breaks p-value ties on χ² (so
   `uux_to_ccx_emmm_qcd0` names the χ²/dof 289 channel). The verdict is
   unchanged; pin it with a test.
4. **Deep-tail p-values.** Replace the truncating `puruspe::gammq` path with a
   non-truncating upper incomplete gamma (add a crate if one fits; the
   AGENTS.md rule on standard primitives applies — do not hand-write one
   unless no maintained crate computes it, and say which you checked), pinned
   by a known-answer test such as Q(2, 65) = 66·e⁻⁶⁵. If you cannot, print a
   bound everywhere a p-value is shown (`stats.rs:274` and `seed-record`).
   Re-run `seed-record --rescreen` over all 55 records before and after and
   show that no verdict changed (diff the two outputs).
