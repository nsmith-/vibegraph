# Research Materials

This directory contains the knowledge bundle, reference implementations, and sample data
supporting the vibegraph LO Monte Carlo event generator.

## Structure

- `kb/` — the knowledge bundle (OKF v0.2): topic concepts, the backlog, decisions,
  sprint records, and the original working notes under `kb/history/notes/`;
  start at `kb/index.md`
- `refs/` — git submodules for reference implementations (MadGraph, ALOHA, UFO, etc.)
- `ufo/` — sample UFO model files for testing (e.g., SM, scalar toy models)

## References

See `refs/README.md` for the current submodule list, key paths within each reference, and instructions for fetching papers and populating submodules.
