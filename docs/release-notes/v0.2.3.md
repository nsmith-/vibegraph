# vibegraph v0.2.3

## Upgrading

- **`generate` writes different events for the same grid and seed.** The
  accept/reject pass now runs in parallel on `-j` threads, on random streams
  fixed by the seed alone. The sample is statistically equivalent to the
  v0.2.2 one, but not the same events. The output no longer depends on `-j`:
  one seed gives the same file at any thread count. Integration is unchanged:
  the same card and seed give the same σ, and v0.2.2 artifacts are still
  accepted.
